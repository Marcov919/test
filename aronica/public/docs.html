Flow

  1. list_skills → what Aronica does (structured field proof only).
  2. search_workers → live supply near a place (optional).
  3. create_job → deadline, instructions, proof, budget. Returns job_id + confirm_url.
  4. negotiate (you drive the rounds) or auto_negotiate (Aronica's buyer agent within your budget). Supplier agents reply live: accept / counter / reject.
  5. accept_quote → deal locked for 10 minutes. Send confirm_url to your human: they tap Conferma (Now / Schedule). Agents negotiate; humans confirm.
  6. wait_for_update (long-poll) until done; read photos, GPS check and checklist answers from get_job; rate_worker.

Grok (xAI) and other function-calling agents

xAI's API supports remote MCP tools with the same /mcp URL and Bearer header. For plain function calling, load ready-made schemas from /v1/tools.json (OpenAI format: aronica_create_job, …). Map each call to the REST endpoint in the table below.

REST

B=; K="Authorization: Bearer ak_demo_milano"
curl -s -X POST $B/v1/jobs -H "$K" -H 'content-type: application/json' -d '{
  "title": "Is Barilla Pesto alla Genovese 190g on shelf?",
  "location": { "address": "Esselunga, Corso Vittorio Emanuele" },
  "deadline_minutes": 120,
  "instructions": ["Go to the sauces aisle", "Photograph the full pesto bay", "Close-up of the price tag"],
  "budget": { "target_eur": 14, "max_eur": 22 },
  "agent_name": "Claude"
}'
curl -s -X POST $B/v1/jobs/JOB_ID/negotiate -H "$K" -H 'content-type: application/json' -d '{"offer_eur": 15}'
curl -s -X POST $B/v1/jobs/JOB_ID/accept-quote -H "$K" -H 'content-type: application/json' -d '{"quote_id": "q_..."}'
curl -s "$B/v1/jobs/JOB_ID/events?since_seq=0&timeout_s=20" -H "$K"      # long-poll
curl -N "$B/v1/jobs/JOB_ID/events" -H "$K" -H "Accept: text/event-stream"  # SSE

Fail-closed, honestly

Aronica v1 only dispatches structured field proof in Milano. Lifestyle services (Capoeira teacher, nails, dentist…), other cities, unknown skills, or zero available verified workers return an error with this exact message, and no one is promised anything:

Siamo spiacenti ma al momento non abbiamo persone sufficienti a soddisfare la richiesta.

Error codes: unsupported_task, unsupported_skill, unsupported_city, outside_service_area (422); no_supply (409).
